# Real-Time Incremental RAG on Pathway — pinned runtime dependencies.
# Python 3.11 (matches the pathwaycom/pathway base image and the local venv).
#
# WHY THIS LIST LOOKS THE WAY IT DOES (non-obvious, learned by verification):
#
# 1. We deliberately do NOT use `pathway[xpack-llm]`. That extra pulls
#    langchain + llama-index + a transitive graph so deep that pip aborts with
#    `resolution-too-deep`. We pin pathway core + only the libs it actually
#    imports, with lower bounds, to keep the resolver shallow & reproducible.
#
# 2. In pathway 0.30.1, `pathway/xpacks/llm/__init__.py` eagerly imports every
#    submodule, and `_parser_utils.py` does a *runtime* (not TYPE_CHECKING)
#    `with optional_imports("xpack-llm-docs"): import docling...`. So although
#    docling / pdf2image / unstructured are documented as "optional", they are
#    in practice MANDATORY just to `import pathway.xpacks.llm` at all. They are
#    pinned here. (The genuinely heavy, feature-gated bits of xpack-llm-docs —
#    paddleocr, unstructured[all-docs] — are NOT needed and intentionally omitted.)
